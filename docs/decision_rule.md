# Правило рішення

Зафіксовано **20.10.2026, до завантаження даних**. Дата коміту — доказ, що пороги не підібрані під результат.

## Питання

Рекламу Metro 2039 побачать усі. **Де вкласти більше** бюджету серед гравців S.T.A.L.K.E.R. 2 у Steam?

## Сегменти

Мова відгуку в Steam: `english`, `ukrainian`, `german`, `french`, `spanish`, `italian`, `polish`.
Запасний рядок — **«5 мов ЄС»**: german, french, spanish, italian, polish.

## Групи

Вікно: S.T.A.L.K.E.R. 2 і Far Cry 5 — 20.11.2024 – 19.10.2026 (UTC); Metro — усі відгуки до 19.10.2026.

| Група | Хто це |
| --- | --- |
| S⁺_L | усі гравці S.T.A.L.K.E.R. 2 з відгуком мовою L |
| S_L | S⁺_L без відгуку на Far Cry 5 |
| F_L | гравці Far Cry 5 з відгуком мовою L без відгуку на S.T.A.L.K.E.R. 2 |
| M | гравці з відгуком хоча б на одну з 3 ігор Metro |
| E | гравці з відгуком на Metro Exodus |
| C_L | спільні: S⁺_L ∩ E |
| O_L | «лише Metro»: автори відгуку на Exodus мовою L без відгуку на S.T.A.L.K.E.R. 2 |

Спільних гравців S.T.A.L.K.E.R. 2 і Far Cry 5 прибираємо **з обох груп**.

## Умови

**Умова A — головна (тепла аудиторія):**
`lift = p_S / p_F ≥ 1.5` **і** `abs(z) ≥ 2.69`,
де `p_S = N(S_L ∩ M) / N(S_L)`, `p_F = N(F_L ∩ M) / N(F_L)`, z — z-тест двох часток.

**Умова B — запобіжник (Metro сподобалась):**
`Δ = pos_C − pos_O ≥ −5 п.п.`,
де `pos` — частка позитивних відгуків на Metro Exodus у групі C_L або O_L.

## Мітки (перевіряємо згори вниз)

| Мітка | Коли | Дія |
| --- | --- | --- |
| Мало даних | у будь-якій групі (S, F, C, O) `n < 100`, або `x < 10`, або `n − x < 10` | як «5 мов ЄС», з позначкою «за середнім» |
| Так | A ✓ і B ✓ | посилений бюджет |
| Тестово | A ✓, B ✗ | A/B-тест посилення |
| Ні | A ✗ | базовий бюджет |

Реклама йде в усі сегменти. Мітка вирішує лише, **де додати більше**.

## Чому такі пороги

- **1.5×** — менша перевага над «нормою» не виправдовує додаткових витрат на рекламу.
- **−5 п.п.** — різниця в задоволеності до 5 п.п. не змінює враження від серії. Більша — сигнал розчарування.
- **abs(z) ≥ 2.69** — поправка Бонферроні: 7 тестів, `α = 0.05 / 7 = 0.0071`.
- **n ≥ 100, x ≥ 10, n − x ≥ 10** — менше даних дає занадто широкий довірчий інтервал.

Пороги — **бізнес-рішення**, а не статистичні константи.

## Висновок за english

English — це весь світ, тому він **загальний тест** гіпотези.

- **english = Так або Тестово** → гіпотеза підтверджена. Діємо за таблицею рішень.
- **english = Ні** → гіпотеза провалена. Усім — базовий бюджет. Сегменти з «Так» отримують лише A/B-тест посилення.

## Що на рішення не впливає

- **p-value** — лише для показу: `p = erfc(abs(z) / sqrt(2))` у SQL. Рішення — за `abs(z)`.
- **Перевірка стійкості:** ліфт за активністю авторів (2–5 · 6–20 · 21+ відгуків). Ліфт ≥ 1.5 у кожній групі → «стійко».
- **Розмір аудиторії** (скільки ще не грали в Metro), теми у відгуках, настрій трейлерів.
